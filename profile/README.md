**Start.cat** — software studio in Barcelona, since 2012.

We design, build and maintain mobile apps, web products and AI automation for demanding clients, including research apps for hospitals and research institutes.

**Open source**

- [tria](https://github.com/startcat/tria) — the engine and CLI of [Lyncat Tria](https://tria.lyn.cat): sorts documents with AI following rules you write in plain language, and never deletes or overwrites anything. `brew install startcat/tap/tria`.
- [agentic-pipelines](https://github.com/startcat/agentic-pipelines) — unattended agentic pipelines on macOS: shell and Claude Agent SDK steps, sandboxed and scheduled with launchd.
- [pipelines-starter](https://github.com/startcat/pipelines-starter) — seven ready-to-use pipelines for it: website checks, stale PRs, a weekly briefing, docs drift, a news digest and more.

The other repositories here are libraries and forks we maintain for client projects.
